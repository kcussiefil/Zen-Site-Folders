# Zen Site Folders v0.2.5

**預先發布／待實機驗證**

### 新增
- 舊 v3 快照仍無法辨識分頁 ID 時，左鍵還原安全中止，不再移動分頁。
- 新增右鍵還原箭頭的**安全拆分**：需明確確認，只將這次整理所建立的 `zsf-` 一般群組解除，不關閉、不重載、不釘選分頁，不動原有 Zia 群組。
- 拆分後原始快照仍保留；核對分頁後再次右鍵並確認，才清除快照。
- 新的 v4 快照保存 URL，只有單一網址匹配且建立時間不晚於快照時才輔助還原，重複網址不進行猜測。

### 已知限制
- 舊 v3 快照沒有 URL，**無法保證復原原本完整排序**；安全拆分不等於精確還原。
- 舊快照出現「5 個分頁無法辨識」並不代表 5 個分頁一定消失。
- 尚未完成 Zen + Zia + Advanced Tab Groups 實機端到端驗證。操作前請備份 Zen Profile。
- Sine 更新是否正確套用，取決於其 GitHub Raw 快取及本機 `updatedAt` 比對；GitHub Release 本身不會修復 Sine 更新偵測。
