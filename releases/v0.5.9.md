# Zen Site Folders v0.5.9

修正 Zia 原生拖曳接手順序及長距離邊緣捲動。保留 Zia 原生預覽與排序，資料夾放開時直接使用最後顯示的預覽落點，避免先插錯位置後再次搬動。

- 因應 Zia 延後初始化，在手勢開始時將相關處理器排到 Zia 之後。
- 原生接手後可連續向上、向下捲動垂直分頁；補償既有 Zia renderer 的捲動座標，不新增第二次排序。
- 限制捲動內容高度，避免拖曳變形持續擴大捲動範圍；原生或使用者自行捲動時暫時讓出控制。
- 取消、放開及銷毀時還原處理器。保留 0.5.8 的巢狀落定防護、整理、還原與展開捲動修正；其他模組僅更新版本標示，CSS 未變。

## 已驗證

macOS 27.2、Zen 1.24b（20261029123729）、Zia 2.114.1、Sine 2.3.4.1c，使用隔離設定檔、新建測試分頁、266px 展開側欄與 macOS OS 滑鼠事件。

- 單一分頁向下、向上各連續捲動 2021px：逐幀遙測未發現來源隱藏或離開可視區；64 個分頁及原群組完整，放開位置符合預覽。
- 資料夾向上、向下：預覽與實際落點一致，均只插入一次，維持普通區，沒有落定後再次搬動。
- native-edge-scroll、drag-feedback、native-single-landing、nested-drop（12 個模型案例）、expand-scroll-lifecycle 針對性回歸及腳本語法檢查通過。未跑完整 CI。

## 已知限制

- 約 60px 的窄圖示側欄模式仍有網站群組零高度問題；上述通過結果限 266px 展開側欄。
- 動畫觀感、輪廓光外觀、完整原生效果比較與 hover 時側欄保持展開，尚未完成視覺驗收；逐幀 DOM 遙測不能代替人工連續影像驗收。
- 大量群組展開造成所選分頁捲動，本輪通過 lifecycle 回歸，未重新進行 GUI 驗收。
- 捲動補償針對 Zia 2.114.1 的內部處理器特徵；不匹配時不介入，不保證其他 Zia 版本。
