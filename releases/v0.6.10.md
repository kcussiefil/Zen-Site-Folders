# Zen Site Folders v0.6.10

Compatibility fix for Zia v2.117.2 / macOS hover-card glass transparency.

- Restores the frosted-glass appearance behind Site Folders' independent hover preview card.
- Mirrors Zia's on-demand compositor approach: apply `will-change: transform` and `backface-visibility: hidden` to the page container only while the Site Folders card is visible.
- Enabled only on macOS while Zia's `zia.cards.blur` preference is active.
- The compositor hint is removed as soon as the card hides; it is not a permanent HDR workaround.
- No changes to preview layout, 0.6.9 real tab opening time, drag-and-drop, sorting, animations or folder data.
- Limitation: HDR video can still temporarily appear washed out while a glass hover card is visible, matching Zia's native hover cards. With the card hidden, HDR output should be unaffected.

Verification: CSS-only scoped change, Node hover regression assertions; native Zen/macOS HDR and blur visual verification required before merging to main.
