# v1.0.7 — Native sort-first tab drag and reliable two-icon grouping preview

## Fixes

- **Native sorting first.** Site Folders never calls `preventDefault` or `stopPropagation` during `dragover`. Zen/Zia owns moving tabs across rows. Dropping before a manual group is fully ready does not call either cancellation method, so the browser receives the native reorder/drop rather than snapping the tab back.
- **Intentional group dwell.** A manual group preview appears only after the drag pointer stays within 3px of the same eligible target tab's central band for **250ms**. Passing through a tab without pausing remains ordinary sorting. The separate horizontal fill remains adjustable in Sine (default 1.2 seconds).
- **Movement cancels preview.** After a candidate starts, deliberately moving more than 3px immediately removes both overlays, unhides the source and close controls, and returns to native sorting without intercepting that event or any subsequent drop. A new stationary centre hover in the same drag can still re-arm grouping.
- **Both site icons always visible.** Remove the previous adjacency-only condition, which silently omitted the lower favicon pair when Zia had already moved the source and target farther apart. Keep independent fixed-position header/pair previews, original favicon sources, 8px separation and the upward animation.
- Preserve original native tab objects, source-first group membership, custom icons, white default folder icon, site grouping, snapshot restore, background-tab drag, and group collapse/expand behaviour.

## Verification

- JavaScript / Node regression: fast one-slot sorting, native early release both before and after preview starts, 250ms stationary gate, motion cancellation, restored controls, guaranteed two-icon creation for non-adjacent tabs, both grouping directions, source-first native membership and scroll/transform-safe positioning.
- Native Zen + Zia: group creation after stable dwell, native drop preservation when hold remains incomplete, same-gesture rearm after ordinary sorting. Includes macOS and Linux synthetic native events and Zia version comparisons.
- **Hardware acceptance required:** Mac trackpad drag A up/down one slot and release immediately; hold centrally until the progress completes; cancel a preview by moving on; test across several tabs. CI synthetic drags cannot prove physical pointer behaviour.

## Rollback

Restore `v1.0.6` or disable manual grouping with `zen.sitefolders.manual_group_drag.enabled=false` in `about:config`, keeping the rest of Site Folders enabled.
