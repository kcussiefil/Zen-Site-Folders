# Zen Site Folders v0.7.2 — Single-page grouping and smart standalone tabs

- Create a new site group only when at least two eligible tabs belong to that site. A single new tab still joins an existing matching group.
- Place eligible independent web tabs below the final ordinary group only on explicit Organize, newest genuine opening time first; old tabs without a reliable clock keep their pre-sort relative order.
- On closing a member of a Site Folders-owned group, once the closed tab actually leaves the native group and exactly one member remains, automatically dissolve it. If that member is selected, preserve the former group slot, including later tab switches. Otherwise place it in the standalone tail using the same time-based ordering without moving manually parked tabs above the groups.
- Manual drag-outs do not trigger auto-dissolution; native Zen/Zia folders, pinned tabs, other groups, and split views remain excluded.
- Each explicit Organize records a fresh pre-sort snapshot. Previously active snapshots are archived for recovery rather than silently overwritten; Undo returns to immediately preceding organize state.
- Does not alter v0.7.1 timestamp logic, hover glass styling, or drag/animation implementation.

Validation: test native time persistence, selection and tab identity, single-site filtering, timestamp fallback, auto dissolve on close only, mixed manual order, undo snapshot, group isolation and scroll stability. Hardware macOS visual checks follow the Sine release.
