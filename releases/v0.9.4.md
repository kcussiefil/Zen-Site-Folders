# Zen Site Folders v0.9.4 — recover background drag after Zen settings

## Changes
- Users verified v0.9.2 drag works physically, but v0.9.3 intermittently stopped working after opening Zen settings. While broken, Browser Console reported `gBrowser` present, native `startTabDrag` a function, `zen.sitefolders.background_drag.enabled=true`, but `window.__zsfBackgroundDragV090` was absent. This confirms the guard was missing, not that a particular Zen/Sine subsystem caused it.
- Keep `site-folders-background-drag.uc.js` **byte-for-byte identical to v0.9.2 and v0.9.3** (blob SHA `2bf96b968f918d47f66adf41f967b6c3d66d7f07`).
- The persistent Site Folders core checks for the missing guard on `TabSelect`, browser `focus`, and a genuine tab `pointerdown`. Only if enabled and native drag is ready, reload the original guard via Sine's local chrome URL. No permanent polling, native drag manipulation, reordering, snapshot or video changes.
- An unsuccessful attempt is capped to one per second of user activity. `window.__zsfBackgroundDragRecoveryV094?.debug()` exposes a bounded status (whether guard exists, number of reinjections, event and last error) for future diagnosis.
- Existing selected-tab color remains exclusively in HDR Guard v0.4.5.

## Verification
- Node tests include a deterministic missing-module scenario after initial success, Zen settings `TabSelect`, browser focus, and true tab presses; verify no redundant reinjection, no disabled-pref override, and bounded retry.
- Real macOS 27.2/Zen 1.24b+Sine+Zia+HG physical acceptance is **not yet verified** for this recovery. Native CI has a known headless drag `drop` omission from earlier releases; do not claim completed real-world drag validation from headless results.

## Rollback
- Reinstall `v0.9.3` (SHA `5ed00e6cd0f89f28c64b55e0423135056382eba1`) to remove this runtime reloader without changing the underlying background-drag engine.
- To stop background drag without disabling grouping, set `zen.sitefolders.background_drag.enabled=false` in `about:config`; toggle back to true to re-enable.
