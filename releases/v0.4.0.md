# Zen Site Folders v0.4.0

**Pre-release｜僅修正開啟資料夾時目前分頁的光暈裁切。**

- 開啟動畫一開始會移除 collapsed 屬性，v0.3.9 的光暈放行樣式因此立即失效，原生展開中的 overflow:hidden 把光暈切成硬邊。
- 延伸同一條樣式至含目前分頁的一般網站群組，讓展開期間繼續保留光暈繪製空間；保留 Zia 的 zia-folder-holding 例外。
- 只有這項 CSS 行為變更。JavaScript 僅更新版本字串，排序、分頁、收合邏輯、快照及還原均未更動。
- 增加真正 Zen DOM 在展開動畫期間的光暈裁切檢查；自動化檢查不等同使用者實機視覺驗收。

更新後完全結束並重新啟動 Zen，無須清除快照或重建分頁。
