# Zen Site Folders v0.5.8

網站群組的同層拖放現在也會防護 Zia 落定階段的直接 DOM 插入，避免已指向其他群組內部的落點繞過防護。

- 補上空資料夾 appendChild、展開資料夾 insertBefore，以及列 before／after 的插入防護；只攔截正在拖曳的自有網站群組。
- 所有插入路徑共用最後已預覽的同層落點，只落定一次；取消時保持原位，不先放錯再搬回。
- 網站群組仍不支援巢狀群組。原生 Zen／Zia 資料夾與其他分頁的插入行為不變。
- 保留 v0.5.7 的原生拖曳接手、dragover 捲動事件放行，以及群組展開動畫完成等待修正；收合、外觀、整理與還原邏輯沒有新增變更。

驗證：12 個受控巢狀落定案例（展開／收合／空資料夾、接受／取消、原位／改變後的預覽落點），及 drag-feedback、native-single-landing、expand-scroll-lifecycle、collapse 與五個腳本語法檢查均通過。巢狀案例亦以本機 Zia 2.114.1 的實際落定函式執行，0.5.7 失敗、0.5.8 通過；倉庫測試預設使用可攜的插入路徑模型，可透過 ZIA_SOURCE 指定實際 Zia 腳本重跑。

限制：受控案例刻意提供群組內部落點，以驗證最後插入防線。尚未從正常滑鼠操作重現使用者的群組消失現象，不能認定這是唯一原因。macOS 實機動畫、捲動與視覺落點尚未驗收，未執行完整 CI。
