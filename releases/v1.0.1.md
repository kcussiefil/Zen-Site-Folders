# Zen Site Folders v1.0.1 — Yab-style favicon hold and stable manual groups

## Visual and interaction changes
- Removed **all manual group color controls**, the color submenu, accent borders, stored color metadata, and special chevron color. Existing v1.0.0 manual groups migrate to neutral native `gray` and share the same transparent Site Folders shell. Names, icons, group IDs and tabs remain intact.
- Removed the semi-transparent `New Folder` row/card overlay.
- Manual tab-to-tab grouping now uses a **single favicon with a thin circular progress ring**, drawn at the original target tab icon position. It appears after a 120ms reveal and fills over 420ms. Only a completed ring allows release-to-create; leaving the target cancels.
- Reference: Yab's open-source `Sources/Fast/ColumnDrag.swift` and `Sources/Fast/TabDropChoice.swift`, which use a distinct target reveal and hold-to-create state. This reimplements the principle for Gecko and Zen/Zia rather than copying native SwiftUI.
- Merge target is locked to the source drag's original unshifted row slots. Stop following Zia's translated hit target when neighboring tabs avoid the drag.
- Clear stale per-tab Zia landing transforms and temporarily suppress unrelated first-frame tab animations before native group insertion. Normal tab reorder, edge drops, inactive/background drag, pinned tabs, split groups and website sorting remain unchanged.

## Testing
- Node regression for locked drag targets after simulated Zia translations, icon-only ring timer, early release and colorless persistent groups.
- Native macOS and Ubuntu Zen+Zia tests for icon-only hold, completion, real group creation, collapse and preview-card behavior.
- Existing native three-consecutive-held-drag CI failure predates this release and remains separate from these changes.

## Sine
- `theme.json` version **1.0.1**, with refreshed `updatedAt`. CI checks the timestamp against the previous tag.

## Rollback
- Reinstall v1.0.0 from the GitHub Releases page, or disable only drag-to-group at `about:config`: `zen.sitefolders.manual_group_drag.enabled=false`.
