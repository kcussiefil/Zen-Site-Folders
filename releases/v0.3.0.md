# Zen Site Folders v0.3.0

**預先發布（Pre-release）：尚未完成 Zen 實機端到端驗證**

### 資料夾行為
- 一般網站群組維持未釘選、最新分頁在上。
- 收合時目前正在看的成員分頁仍常駐在群組名稱下方；其他成員正常收起。切換到其他群組後同步更新。
- 移除阻斷 Zia 開合動畫的整個容器 `display:none` 與 `max-height:0` 覆寫；交由 Zen/Zia 原生 420ms 彈跳處理，避免雙重動畫。

### 右鍵選單
- 「解除群組」改為「解散群組」。
- 「轉為 Zen 資料夾（會釘選）」改為「轉為 Zen 分頁夾（上方釘選）」。
- 「刪除群組（關閉分頁）」改為「刪除群組」。
- 危險操作只確認一次；若有整理快照，確認後自動封存備份、驗證寫入，失敗就停止。解散群組保留分頁，轉為 Zen 分頁夾會釘選，刪除群組會關閉分頁。

### 快速預覽（方案 B）
- 清單直接使用 Zia 的行列 CSS 類別、已選取光邊、字型與間距。
- 依 Zia 的 `zia.cards.blur` 設定顯示透明玻璃（76% 色彩混合、blur 24px、saturate 1.6）；圓角與光邊沿用 Zia 變數。
- 可使用觸控板上下捲動，採十列高度上限、隱藏捲軸；刷新清單保持捲動位置。
- 預覽內可選分頁、明確新增分頁；按滑鼠顯示的關閉、靜音圖示才執行對應操作。
- 只作用於 `tab-group[data-zsf-site]`，不修改 Zia 原生資料夾。

### 安全／驗證限制
- **核心排序、快照、還原與雙指安全拆分的程式碼沒有變更**（只有版本旗標更新）。
- 已加入模擬測試及 GitHub Actions，但不等同實際 Zen + Zia 瀏覽器 UI 測試。建議先備份 Zen Profile，於測試 Space 驗證。
- 如果 Zia 停用，Zia 的彈跳與玻璃樣式不保證存在；其原生動畫與卡片偏好仍由 Zia 控制。
