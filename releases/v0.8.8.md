# Zen Site Folders v0.8.8 — Theme-aware group-title hover

## Changes
- Display the same live hover color as ordinary Zia tabs on Site Folders group titles, using Zia's `--zia-tab-hover-bg` token. It follows dark and light Space themes; a `currentColor` blend is used only when Zia is absent.
- Remove the collapsed-group rule that forcibly painted the title transparent even while the pointer hovered. Expanded and collapsed site group titles now have consistent hover feedback.
- Preserve transparent idle headers, custom site icons, native expand/collapse, drag/drop targets, group frame suppression, and preview cards.

## Compatibility / known limitations
- Limited to Site Folders-owned ordinary group labels when the Zen sidebar is expanded; split views, user-created groups and ordinary tabs are unchanged.
- Physical macOS/Sine/Zia appearance still requires validation on the actual installed environment.

## Verification
- Added Node regression assertions for the live theme token, both collapsed and expanded selectors, transparent rest state, light-space text and drag-target guards.
- Existing Node and Zen 1.24b plus pinned Zia integration jobs remain applicable and must be assessed before merge.

## Rollback
If Sine allows, revert to v0.8.7. Otherwise temporarily disable Site Folders rather than deleting tab sessions, profile data or saved organizer snapshots.
