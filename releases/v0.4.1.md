# Zen Site Folders v0.4.1

**Pre-release｜展開資料夾時垂直分頁位置及影片播放效能改善，尚待實機驗證**

- 保留 v0.4.0 的 Zen/Zia 原生微彈跳，不重做任何 JS 高度動畫。
- 針對包含本工具群組的工作區關閉 Gecko 捲動錨定補償，避免展開群組的高度動畫讓目前 scrollTop 自動往下增加；不阻止觸控板滾動。
- 開啟中的網站群組不再套用整層 `clip-path`，減輕正在播放影片、音量波形動態更新時的重繪成本，並仍保持選取分頁光暈可見；**關閉中的群組仍保留用於點擊命中的裁切保護**。
- 原本每次 `collapsed` 變更與 `TabSelect` 都掃描全部群組，現改為更新相關群組，結構變動用單一動畫影格合併掃描。
- 真正 Zen + Zia 的測試會加入：含 `soundplaying` 分頁時開啟資料夾的 scrollTop 穩定、選取播放分頁的原生彈跳動畫長度、目前分頁光暈、還原/拆分/拖曳等原有回歸項目。
- `soundplaying` 測試使用真實分頁 DOM 和聲音標記，但非影片串流/GPU 播放壓力測試。**macOS 實機手感及播放中的實測仍未確認**。
- 不修改 Zia 套件、不變更 SessionStore 快照、不關閉或重新建立現有分頁、不影響 Black Sheep POS。

請先在測試 Space 驗證；若使用中發現捲動行為不正常，不要自行清除快照。
