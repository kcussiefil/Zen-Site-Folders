# Zen Site Folders v0.3.2

**Pre-release — 待 Zen + Zia macOS 實機驗證**

## 修正

- 當資料夾靠近視窗下方、卡片內容較長時，右側預覽不再越出可視範圍；清單保持可上下捲動，最後的「開啟新分頁」可觸及。
- 位置計算改用不受縮放動畫影響的布局尺寸，並限制卡片及清單高度為視窗高度扣除 16px。
- 縮短首次預覽等待時間，避免滑鼠在同群組圖示與文字間移動反覆觸發等待。
- 重新啟動 Zia 風格的 260ms 彈性進場動畫，滑鼠離開時增加 120ms 退場動畫；切換已開啟卡片時不反覆播放。
- 用 Zia 的實際分頁縮排量測、原生音量圖示尺寸與邊距，修正音量圖示與文字之間過大的空白。
- 右鍵群組選單保留原本目標，解決第一次點「解散群組」沒有反應。
- 還原箭頭的雙指點按先攔截 `contextmenu` 再開啟安全拆分確認，避免同時觸發網頁右鍵選單。

## 安全與限制

- 不變更 SessionStore 快照格式、不清除既有備份、不自動重新分類或移動分頁。
- 一般網站群組維持未釘選與最新分頁在最上方。
- Zia 原生資料夾、收合穩態控制與中文選單的其他操作不變。
- GitHub Actions 模擬測試並非 Zen 實機測試；安裝後請先用測試群組檢查長清單與右鍵行為。
