# Zen Site Folders v0.8.9 — Group title / first-tab breathing room

## Changes
- Add 3px of visual clearance between a Site Folders group title and its first member tab, making semi-transparent selected-tab fills easier to distinguish from the group title hover background.
- Retain Zia's native 5px folder spacing variable and exchange equal amounts between the negative top margin and positive bottom padding. The group's net flow height is unchanged (default `-2px` top and `+2px` bottom instead of `-5px` and `+5px`).
- Apply the same compensation whether the site group is expanded or collapsed, avoiding a state-driven geometry switch during native Zia/Zen open-close animation.
- Keep all member-tab heights, selected colors, group header hover, preview cards, clipping, dragging, scroll anchoring, split-view exclusion, and underlying JavaScript unchanged.

## Testing and limitations
- CSS regression covers the selector, balanced values under different Zia gap settings, and lack of height/transform/animation overrides.
- Existing Node and Zen/Zia browser integration CI are required before merging. Physical Zen/macOS/Sine check is still required for subjective spacing and drag/scroll performance.
- Scope: owned site groups only when the sidebar is expanded; other Zen groups, split view, and ordinary tabs are unchanged.

## Rollback
- Revert to v0.8.8 in Sine if the native close/open animation or pointer positions regress.
