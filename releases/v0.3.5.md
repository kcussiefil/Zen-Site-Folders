# Zen Site Folders v0.3.5

**Pre-release — 需 macOS Zen + Zia 實機確認**

### 拖曳網站群組時的視覺回饋
- 開始拖動一般網站資料夾時，顯示跟隨游標的半透明資料夾預覽（favicon 與名稱）。
- 來源列降低透明度及顯示淡虛線，明確知道目前正在拖哪個資料夾。
- 移到同工作區、同層級的其他資料夾或普通分頁旁邊時，顯示細插入線與「移到某項上方／下方」文字提示。
- 超出判定範圍或切換工作區時不顯示有效放置提示；放開、取消或原生拖曳結束時移除浮動視覺層。
- 不另建群組、不實際移動分頁、不改釘選狀態；保留 Zen 與 Zia 對原生拖放的處理及最終落點判定。

### 不變的功能與安全
- 網站分類、群組開合、目前分頁常駐、Zia 原生選取樣式、音量波形與右側快速預覽不變。
- SessionStore 快照、Undo、雙指點按安全拆分、繁中右鍵選單均未改。
- 新增單元模擬測試涵蓋群組預覽、插入位置、無效區域、事件隔離與清理；模擬測試不代表 Zen 真實畫面已完成驗證。
