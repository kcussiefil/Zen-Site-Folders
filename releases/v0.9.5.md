# Zen Site Folders v0.9.5 — match Zia's asleep-tab dimming

## Changes
- The custom collapsed-group preview follows Zia's `Dim asleep tabs, essentials and folders` preference (`zia.tabs.dim-asleep`). When disabled, the custom rows remain unchanged.
- Use Firefox's actual `pending` attribute for unloaded tabs; selected tabs and the New Tab action remain bright.
- Match Zia's filter strengths: dark mode favicon 0.55/title 0.60, light mode favicon 0.75/title 0.80.
- Observe `pending` / selection changes only while the preview is open and change affected row state in place, with no full list rerender or polling.
- Preserve Zia/HG card paint, scroll, drag, positioning, animations, muted indicators, and existing commands.

## Verification
- Added hover-card regression assertions for pref gating, dark/light styling, pending-to-loaded transitions, non-rerender, selected tab, New Tab action, observer lifecycle, and version.
- CI covers syntax, Node tests, and headless native Zen/Zia scenarios. These do not replace macOS hands-on visual verification.

## Rollback
- Reinstall v0.9.4 from GitHub Releases, or revert the v0.9.5 commit.
