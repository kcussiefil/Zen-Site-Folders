# Zen Site Folders v0.8.1 — Split-view drag re-entry stabilization

## Changes
- Fix repeated native `animateExpand` calls when a native Zen split-view wrapper leaves or re-enters an **already expanded** Site Folder.
- Preserve the original expanded layout, instead of temporarily clipping the group container during a redundant 180 ms animation. This targets one source of the grey blank row and shifting layout reported during repeated split-view drags in v0.8.0.
- Retain Zen's native split-aware expand/collapse animation for genuine closed-to-open transitions, including recovery of a negative `groupStart.marginTop`.
- Add Node regressions for repeated split members, selection changes, exit and re-entry, plus a real Zen/Zia integration test for split wrapper re-entry.

## Compatibility / known limitations
- This is a targeted stabilization, **not a claim that all split-view drag bugs are fixed**. Repeated physical Zia drag gestures, drop placeholders, other native split ownership transitions and the user's full macOS 27.2 workflow remain unverified.
- The macOS CI bottom-edge WebDriver pointer test has an independent failure; do not claim a fully green CI suite.
- No change to Zia's own drag code, Site Folders' drag sorting, context menus or visual styling.

## Verification
- Node regression tests passed in PR #46.
- Native Zen 1.24b + pinned Zia split exit/re-entry geometry test passed on Linux and macOS (PR #46).
- Physical macOS 27.2 / Sine acceptance was not performed. Verify split moving between multiple Site Folders, especially rapid repeat dragging and expand/collapse.

## Rollback
- If a later Sine build cannot install an older version, disable the Site Folders MOD temporarily rather than continuing repeated split-view drags on an unstable version.
