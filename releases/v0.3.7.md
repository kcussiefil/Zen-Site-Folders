# Zen Site Folders v0.3.7

**Pre-release｜需 macOS Zen + Zia 實際驗證**

### 1. 資料夾開合與切換目前分頁
- 移除先前自製的 420ms 高度動畫、固定時程隱藏與收合後強制 `display:none/flex` 的 CSS，以免和 Zen／Zia 原生動畫競爭造成末端抖動或選取分頁突然切換。
- 交還給 Zen／Zia 已支援普通 `tab-group` 的原生開合與選取分頁機制；啟動時清理 v0.3.6 殘留動畫狀態。沒有額外計時器或第二套高度動畫。
- **提醒**：真實 UI 動畫是否完全一致仍待 Zen 實機驗證；若選取分頁在收合時未常駐，請回報以便針對 Zen 的原生狀態整合調整，不會以固定計時器修補。

### 2. 實際拖曳排序
- 使用者在群組內手動拖曳後，取消原本 `TabGrouped` 事件 80ms 後強制「新到舊」重排，避免分頁回彈到舊順序。
- 擴大資料夾上方的有效落點至**普通分頁區第一項之前**，但不跨入上方釘選區。
- 偵測 Zen／Zia 原生拖放結果；若同層位置仍不正確，使用原生 `gBrowser.moveTabBefore/After` 校正群組或資料夾內成員的順序，不移出群組，不釘選。
- 拖曳中的預覽及插入線也支援資料夾內成員；真正落點仍需原生 API 成功，若落點無法確認不進行跨層移動。

### 3. 安全拆分與解散不跳確認
- 右鍵「解散群組」以及雙指點按還原箭頭「安全拆分」，完成原有檢查與備份後立即進行，無需第二次確認。
- 救援後快照及還原箭頭先保留，核對後再次點按才會在沒有殘留群組的前提下封存清除；此步也不跳確認。
- 「刪除群組」（會關分頁）及「轉為 Zen 分頁夾」（移往上方釘選）仍要求確認。
- 只刪除多餘的確認對話框，不放寬快照封存、讀回檢查、未知群組保護與原順序驗證。

### 驗證
- GitHub Actions 新版回歸測試：開合動畫不被雙重控制、成員可手動排序、群組可拖到最前、無效落點阻止移動、直接安全拆分與必要封存。
- **尚未在使用者 macOS Zen 實機測試**。建議備份 Profile 並在測試工作區先確認。
