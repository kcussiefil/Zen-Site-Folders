# Zen Site Folders v0.9.0 — Background tab drag without activation

## Changes
- Hold and drag an unselected tab without first switching to that tab or activating a discarded/sleeping page.
- Preserve ordinary click behavior: releasing a genuine click over that tab selects it.
- Keep Zen/Zia's existing drag positioning, live avoidance and group landing logic; no native drag events are cancelled or replaced.
- Preserve the real source in the native drag payload, without unintentionally dragging the previously active tab.
- Leave selected tabs, modifier clicks, interactive tab buttons, Glance, and native split-view groups on their original paths.
- Add a separate Sine toggle, "Drag background tabs without activating or loading them" (enabled by default).

## Compatibility / known limitations
- Zen's private selection and drag accessors are wrapped defensively. If they are unavailable or non-configurable, this optional feature fails closed and restores native behavior.
- The short post-drop selection guard is for Zia/native completion only and does not delay the drop itself.
- This prevents selection-triggered wakeups; background activity initiated by Zen or websites for unrelated reasons is outside its scope.
- Sine 2.3+ with JavaScript mods enabled is required. Existing Site Folders grouping, snapshots, split guard, and HDR Guard are unchanged.

## Verification
- JavaScript syntax, isolated tab-selection and native-drag-payload regression tests are part of CI.
- Existing Node regressions and pinned Zen 1.24b + Zia native-browser workflows must pass on the PR before merging.
- Physical macOS + Zia + Sine acceptance remains necessary for subjective pointer timing and unloaded-tab behavior.
