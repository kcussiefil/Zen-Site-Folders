# Zen Site Folders v0.8.7 — Natural proportions, balanced ink

## Changes
The v0.8.6 image-only nonuniform transforms made native Zen's round Undo glyph look oval. Remove all three nonuniform glyph transforms, preserve each original Zen asset and intrinsic aspect ratio.

Measured v0.8.5 artwork footprints on the user's screenshot were Undo 22×26, Group 26×22 and Clear 18×23 physical pixels. Using **equal-axis icon sizes** balances approximate painted glyph area without distorting their natural silhouettes:
- Undo/Restore: **14 × 14 CSS px** (original round glyph restored).
- Group/Organize: **15 × 15 CSS px**.
- Native Clear: **14 × 14 CSS px**, image opacity **0.88** to balance its solid-fill artwork against the outlined Undo and Folder glyphs.

All three images remain centered with **no transform** and **no icon animation**. The click target remains **20 × 20 CSS px** in the same right-hand location. No changes to icon assets, commands, hover-only fade, line/wave geometry, Undo snapshot condition, drag/drop or saved session state.

## Tests
- Node contract tests assert independent icon sizes, no distorted SVG image transforms, preserved target sizes, native Clear function and wave.
- Native Zen 1.24b + pinned Zia macOS/Linux headless WebDriver pointer tests verify actual image dimensions and computed transform=none, separator fade, right-side positions, conditional Undo, and real native Clear click.
