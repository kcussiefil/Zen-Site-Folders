# Zen Site Folders v0.6.3

- 加快復原箭頭的快照還原。符合條件的分頁可用一次 Zen 原生操作解組並回到原位，保留分頁物件與快照核對流程。
- 普通分頁變動減少觸發整欄群組掃描。拖曳捲到邊界時省略無效寫入，預覽關閉後停止更新時間。

隔離 macOS Zen 1.24b 中，96 個分頁交錯分成 12 個網站群組，另有一個原有手動群組。相較前一候選版 local.2，三輪復原中位數由 3.00 秒降至 2.08 秒。多群組捲動的影格間隔中位數約 16.7 ms，未量到明顯提速。

已知限制沿自 0.6.2。側欄距頂端的距離不足以補償上一群組收回的高度時，點選目標仍可能上移。長距離拖曳已在前一候選版確認上下捲動和原生放開，逐影格落點一致性仍待驗收。
