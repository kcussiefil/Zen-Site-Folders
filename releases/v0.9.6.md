# Zen Site Folders v0.9.6 — group-header favicon brightness follows Zia

## Changes
- Site-group header favicons now match the brightness of unloaded standalone-tab icons when **every member tab is pending/unloaded**.
- If **any member tab loads**, the group favicon immediately returns to the normal loaded-tab brightness; unloading the last loaded member dims it again.
- Uses the same CSS `:has()` predicate as Zia's native all-asleep group label and respects the live `zia.tabs.dim-asleep` preference.
- Compensates only the favicon for Zia's parent group-label filter: dark 0.60 × 0.9166666667 = 0.55; light 0.80 × 0.9375 = 0.75.
- No new JavaScript, polling, observers, fixed colors, group text/arrow adjustments, or layout/drag/animation changes.

## Verification
- Added `tests/group-header-asleep.test.cjs` for state transition policy, live preference gate, exact dimming ratios, selector isolation and unchanged geometry.
- Existing Node regression suite and headless native Zen + Zia Linux/macOS checks run through GitHub Actions.
- Physical macOS visual verification remains separate from CI.
