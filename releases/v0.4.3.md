# Zen Site Folders v0.4.3

**拖曳視覺整理、整組讓位動畫與清單邊緣自動捲動**

- 拖曳本站群組內的分頁或整個網站群組時，隱藏原生灰色拖曳縮圖和來源橫條，保留浮動提示卡及插入位置線；不改其他普通分頁、Essentials、Zen 資料夾或 Library 的拖曳顯示。
- 整組資料夾拖曳時，原位置與目標位置之間的群組及一般分頁會暫時上下平移閃避；實際 DOM 順序仍在放開後才由原生 Zen/Zia 與安全校正處理。
- 游標停在目前 Space 普通分頁列頂部／底部約 52px 範圍可持續捲動，並依實際 scrollTop 更新落點；Esc、放開、失焦、切換工作區均清除拖曳狀態。
- 沿用 Zia 動畫，不修改 Zia 套件。不關閉、釘選或重建分頁，不動 SessionStore 快照及復原流程。
- **自動化測試限制**：合成拖曳事件與無視窗 Zen 測試不能替代 macOS 實體觸控板及 OS 拖曳影像的實測。

更新後完全退出並重新啟動 Zen，不需清除快照或重建分頁。
