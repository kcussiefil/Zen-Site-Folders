# Zen Site Folders v0.7.7 — XUL context menu pointer-tracking correction

This is a narrow candidate fix for Site Folders group right-click menus on macOS when Zen Context Menu's "Zen's own menus on macOS" is enabled.

- Open the custom `#zsf-site-group-menu` with the XUL `isContextMenu=true` flag, instead of opening it as a generic popup. Firefox/Gecko documents this flag as controlling context-menu highlighting and interaction with other open menus.
- Preserve all existing Chinese menu entries, workspace submenu construction, action callbacks, group data protection, confirmation flows and regular tab-menu customizations.
- Add regression coverage asserting the context-menu flag, without synthetic `mousemove` listeners, polling or timers.
- Keep HG, Zia drag/drop, folder styling and release history unchanged.

Validation: Node/CI regression tests verify invocation and existing logic. This test cannot simulate the user's macOS 27.2 native popup rendering and actual mouse tracking. **Mac device-level acceptance is pending**; the flag is a grounded fix hypothesis, not a verified complete resolution. If behavior remains stuck, use Firefox Browser Toolbox to inspect popup event handling and Zen Context Menu interactions before adding workarounds.
