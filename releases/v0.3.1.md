# Zen Site Folders v0.3.1

**預先發布（Pre-release）— 修正 v0.3.0 一般網站群組無法收合**

### 修正
- 移除子容器無條件的 `display:flex !important`，避免蓋過 Zen 原生的 `collapsed` 顯示狀態。
- 收合事件先保留 Zen/Zia 的 420ms 彈跳動畫，待約 470ms 後進行最終收合，確保非目前分頁確實隱藏。
- 若目前正在查看的分頁就在已收合群組中，只保留該分頁；其餘成員隱藏，避免使用者找不到目前分頁。
- 展開立即解除收合保護；快速開／關會取消過期計時，避免展開後被再次隱藏。
- 已收合群組在重啟後立即恢復正確顯示。

### 不變
- 一般群組不釘選；網站分頁依最新在上排序。
- Zia 原生資料夾、右鍵繁體中文選單、快速預覽玻璃樣式、SessionStore 快照、Undo 與安全拆分均不修改。
- 沒有新增分頁移動、釘選、關閉或還原 API 呼叫。

### 驗證
- 新增 Node 模擬回歸測試，覆蓋已收合工作階段、正常開合、快速切換、屬性變化、與 Zia 資料夾隔離、清理事件。
- GitHub Actions 驗證不等於真實 Zen 介面測試；請先備份 Zen Profile，並在測試工作區驗證。
