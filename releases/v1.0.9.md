# v1.0.9 — Calmer Context Menu: reorder Create Group within one native section

## Changes

- The existing **建立群組** action is inserted immediately **before Zen's native Change Icon menu command** rather than appended at the very end of `tabContextMenu`.
- This is intentionally the same native anchor used by HDR Guard **v0.4.6** for `變更選取分頁顏色`. They now occupy the same separator-bounded section for `sinazadeh/zen-calmer-context-menu` regardless of which MOD loads first; users can drag them into their desired order **within that section**.
- The insertion occurs before Change Icon, rather than after it, so Zen's adjacent-sibling rule for the following hidden separator remains intact. A missing Change Icon falls back to Bookmark Tab, Bookmark Selected Tabs, then Duplicate Tab without creating or deleting native separators.
- No changes to selected-tab color ownership, context-menu command behavior, multi-selection validation, manual group storage, default icons, title, hover cards, Zia styles, background tab sorting, or the removal of drag-to-create groups in v1.0.8.

## Verification

- Node regression checks native separator ordering, actual `insertBefore` behavior, both module load orders (HDR Guard inserted before/after Site Folders), and unchanged right-click group creation / stored native groups.
- Zen/Zia browser regression checks insertion before Change Icon; when HDR Guard is present, it additionally checks the two commands are in the same native separator section.
- CI cannot certify the third-party Calmer setting-to-popup browser interaction without that MOD installed. **macOS manual acceptance:** update both Site Folders v1.0.9 and HDR Guard v0.4.6; restart Zen; right-click an ordinary tab, then multiselect tabs and right-click so Calmer records both menu items; reorder them in Calmer's settings and reopen the menu. Do not expect cross-separator drag support.

## Rollback

- Use the v1.0.8 Sine/GitHub release and the preserved `backup/v1.0.8-before-v1.0.9` branch to restore previous menu placement. No persisted manual group data changes are involved.
