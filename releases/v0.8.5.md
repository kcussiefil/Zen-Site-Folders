# Zen Site Folders v0.8.5 — Separator icon optical size adjustment

## Change
- Undo (native `arrow-rotate-anticlockwise.svg`): **15 × 15px** (unchanged).
- Group/Organize (native `folder.svg`): **16 × 16px** (previously 15px).
- Clear (Zen-native `dart-down.svg`): **13 × 13px** (previously 15px).

Only the image artwork dimensions change. All clickable toolbar buttons remain **20 × 20px**, center aligned, fixed at the same right-side offsets: Undo → Group → Clear. The separator line, hover-only opacity fade, wave, Ctrl/secondary-click rescue, Undo visibility tied to snapshots, and Zen-native Clear command retain v0.8.4 behavior.

## Verification
- Node tests assert individual icon width/height/min/max values and unchanged 20px button target, positions, and Clear fallback.
- Native Zen 1.24b + Zia integration verifies measured icon geometry and existing separator hover / native Clear behavior.
- macOS user/Sine physical appearance acceptance remains unverified.

## Rollback
If Sine does not support version selection and regression occurs, temporarily disable Site Folders rather than changing or deleting user tabs.
