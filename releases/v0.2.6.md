# Zen Site Folders v0.2.6

**預先發布 / 待 Zen 實機驗證**

### 修正

- 改用獨立的左鍵「拆」按鈕啟動安全拆分，解決 Zen/Zia 可能攔截「右鍵還原箭頭」事件的問題。
- 「拆」按鈕只在本工作區具有可救援的 v3/v4 快照時出現；整理／還原操作期間暫時停用。
- 優先採用 Firefox 原生確認對話框；確認流程無法開啟時，不移動分頁。
- 第一次確認只解除本 Mod 快照記錄的網站群組，不關閉、不重新載入、不釘選分頁，保留備份；核對後再次按「拆」並確認才會清除快照。

### 限制與驗證

- 舊 v3 快照缺少網址資訊，因此安全拆分無法保證精確還原原本的排序。
- JavaScript 語法及模擬的 5 分頁拆分、保留快照、二次確認清除已通過。尚未在實際 Zen / Zia / Advanced Tab Groups 環境完成端到端驗證。
- Sine 更新依 `updatedAt` 比較；這個 Release 本身不會強制安裝更新。
