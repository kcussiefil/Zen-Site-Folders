# Zen Site Folders v0.8.3 — Separator-local action icons

## Changes
- Hide the two Site Folders separator controls (Organize, Undo) and Zen's native Clear control outside **the 22px separator row itself**. Hovering the rest of the sidebar must not reveal them.
- Release the entire width and margins of hidden buttons; the existing native `toolbarseparator flex=1` draws a long line at rest and shortens to accommodate controls on hover.
- Replace the visible "Clear" text with **Zen's bundled `dart-down.svg`**. Preserve the native `cmd_zenCloseUnpinnedTabs` command, the `can-close` availability marker, and the `zen.view.show-clear-tabs-button` preference (no forced `display:flex` on Clear).
- Preserve the existing Site Folders action icons and commands, right-click rescue on Undo, and hidden Undo when no valid snapshot exists.
- Preserve the existing sorting SVG wave. The per-frame wave positioning now excludes buttons whose animated width is zero, so it tracks the expanded or shortened line without ghost gaps.
- Add static regression assertions and a headless native Zen + Zia WebDriver hover layout regression.

## Non-changes
- No tab moves, group restoration, split-view, Zia gesture handling, context-menu, HDR/SDR, or data migration changes.
- No additional spacer DOM nodes or alternative separator graphics.

## Verification and known limits
- Node tests plus native pinned Zen 1.24b + Zia headless macOS/Linux hover geometry.
- Exact physical macOS 27.2/Sine interaction remains unverified until user acceptance.
- Existing unrelated native pointer CI failures may persist.

## Rollback
- If Sine cannot install historical versions, disable Site Folders temporarily, rather than changing users' tabs.
