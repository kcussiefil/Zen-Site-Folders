# Zen Site Folders v0.3.3

**Pre-release｜尚待 macOS Zen + Zia 實機驗證**

### 音訊動畫
- 右側網站群組快速預覽，移除靜態喇叭圖示。
- 如果 Zia 已對原始分頁產生 `--zia-sound-wave`／`--zia-sound-muted`，預覽卡片直接使用其原生四條動畫 SVG；音量與靜音狀態同步。
- 音量圖示與標題間距改為緊湊配置，不再把 8px 行間距與喇叭的大邊距重複疊加。
- Zia 尚未繪製動畫時才使用 Zia 自己的靜態波形圖示備援。

### 資料夾開合動畫
- 完全取消 v0.3.1/0.3.2 固定等 470ms 然後 display:none 的機制。
- 讓原生 Zen/Zia 420ms 群組幾何動畫優先控制動態高度。若這個一般群組沒有觸發 Zia 原生高度動畫，才用本 Mod 的 WAAPI 420ms 高度彈簧補足。
- 最終隱藏狀態以動畫 `finished` 而非固定時鐘控制；按下後立即動畫，支援中途反向。
- 收合時如果正在查看群組內的分頁，該分頁仍留在群組名稱下方。

### 範圍與安全
- 只改網站群組的收合顯示及懸停卡片音訊，不動 Zen/Zia 自己的原生分頁夾。
- 不改分頁排序、釘選行為、SessionStore 快照結構、Undo、救援或群組右鍵操作。
- Node 模擬回歸測試涵蓋實際高度動畫、Zia 動畫優先、選取分頁常駐、快速反向開合及原生音訊 CSS 變數。
- **尚未在使用者 Zen 實機完成視覺與互動測試**。更新前先備份 Profile，在測試 Space 驗證；如有異常，停用本版並回報。
