# Zen Site Folders v0.7.5 — Light theme text contrast

Fix poor text contrast of **Site Folders group names** when Zen uses a
light/white coloured Space. Zia marks these themes with `zia-light`.

- ZSF intentionally suppresses group tint by setting
  `--zia-folder-swatch: transparent`. Zia normally mixes this swatch
  into its light-space group-label text, unintentionally producing
  translucent dark text.
- In Zia light mode only, scope ZSF-owned site folder labels to
  `color: var(--zia-sidebar-ink, rgb(28,28,32))`, retaining the same
  deep ink and contrast as Zia's native light-space labels.
- Dark themes, native Zen/Zia folders, regular tabs, selected-tab fill,
  hover-glass and edge styling, layout, collapse, scroll/drag animations,
  timestamps, undo and group sorting are not changed.
- Add direct CSS regression checks and a native Zen + Zia case which
  checks light/dark computed label colours and group/tab identity.

Hardware macOS verification can confirm final visual contrast with
the user's actual white Space colour and Transparent Mode stack.
