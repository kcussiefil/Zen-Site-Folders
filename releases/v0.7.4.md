# Zen Site Folders v0.7.4 — 移除舊毛玻璃實驗齒輪

此版只處理獨立的毛玻璃實驗 MOD，Site Folders 主要功能維持 v0.7.3，未修改預覽的毛玻璃、邊線、分頁時間、群組、拖曳或動畫。

- 舊實驗 MOD Zen Transparent Blur A/B + Local Test 更新為 v0.2.1；保留原 Sine ID 以供舊安裝正常更新。
- v0.2.1 不再提供偏好設定（無齒輪），所有實驗 CSS 停用。
- 刪除舊實驗設定檔，增加回歸測試避免重新出現。

已獨立安裝舊測試 MOD 的使用者仍需在 Sine 更新該實驗 MOD 至 v0.2.1，或直接解除安裝並重啟 Zen。更新 Site Folders v0.7.4 不會自動卸載另外一個 MOD。
