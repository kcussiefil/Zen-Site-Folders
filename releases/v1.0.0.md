# Zen Site Folders v1.0.0 — manual group parity and usable drag-to-group

## Fixes
- **Manual groups now share the entire Site Folders transparent/Zia template**, not merely their favicon size. Background, label geometry, spacing, selected/collapsed layout, and themed hover match the established automatic site groups.
- **Collapsing and expanding now truly hides/shows member rows** via the existing native Zen/Zia animation bridge. Collapsed manual groups also use the existing read-only Site Folders preview card, with the same background-link insertion handling.
- **Native color control:** Right-click a manually created group and choose **變更顏色** to select one of nine official Firefox tab-group colors. Choices are saved with the native group and manual-group ID and shown as a subtle header accent, rather than reverting to a solid colored background. Automatic website groups retain their transparent identity and do not show this menu.
- **Much easier two-tab grouping:** Increase merge target from the central 50% of tab height to 80%, and reduce preview activation from 180ms to 95ms. Keep the outer edge zones dedicated to normal Zen/Zia drag ordering.
- Share the existing group drag/top-drop controllers, while preserving manual `data-zsf-manual` identity and keeping automatic `data-zsf-site` ownership separate. **Do not change the automatic sorter or snapshot semantics.**
- Use Firefox-native `gray` (not `grey`) for neutral tab-group color.

## Verification
- Node integration regression tests and new source/visual parity test.
- Native Zen 1.24b + Zia tests on macOS and Ubuntu validate actual group collapse/expand, transparent template, hover preview, native group color persistence, and unchanged tab objects.
- Existing consecutive held-background-drag check has been known to fail in published v0.9.5–v0.9.9 and remains a separate issue.
- Native macOS automation does not replace user testing on the daily profile, especially exact touchpad drag feel.

## Updating and rollback
- Upgrade through Sine. Manifest `version: 1.0.0` and `updatedAt` have both advanced, with a CI guard against stale timestamps.
- To disable only drag-to-group: `about:config` → `zen.sitefolders.manual_group_drag.enabled=false`; multi-select context-menu grouping remains available.
- To roll back, reinstall the v0.9.9 Release. Existing manually created groups remain native groups.
