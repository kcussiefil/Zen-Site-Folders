# Zen Site Folders v0.2.8

**預先發布／待 Zen 實機驗證**

### 新增

- 方案 B：保留一般 **未釘選 Tab Group**，不用會把分頁移至上方的 Zen 原生資料夾。
- 取消 Advanced Tab Groups 後仍由本 Mod 顯示網站群組標題、favicon、分頁縮排和收合狀態。
- 新增獨立的 Zia 風格懸停卡片：滑鼠停在已收合網站群組上，右側快速查看所有成員；點選成員切換分頁，明確點擊加號時可在該群組新增分頁。
- 懸停卡片使用自己的 DOM 與事件監聽，不修改 Zia 的內部函式或覆蓋 Zia 原生資料夾的預覽；可讀取 Zia 色彩變數提供近似樣式。
- 只對本 Mod 建立的群組移除彩色底、外框及裝飾，保留中性色 hover、箭頭與動畫。

### 不變的安全邊界

- 沒有改動資料夾整理、SessionStore 快照、Undo、雙指點按安全拆分、群組 ID 或已存分頁資料。
- 沒有增加分頁自動釘選或自動關閉函式。
- 現有手動建立的 Zia / Zen 群組不套用新卡片。
- 需要啟用 Firefox 原生分頁群組偏好 `browser.tabs.groups.enabled`，不必安裝 Advanced Tab Groups。
- 尚未在 Zen + Zia 實機完成端到端驗證；使用前請先備份 Zen Profile，先在測試 Space 驗證展開、收合、預覽與新分頁。

### 自動化驗證

- JavaScript 語法與單元模擬測試（滑鼠懸停、完整清單、分頁切換、不干擾原生資料夾、明確新增分頁、清理事件）。
- GitHub Actions PR 驗證工作流程。
