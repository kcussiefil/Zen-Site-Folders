# Zen Site Folders v0.8.2 — Deny split-view drops into groups

## Changes
- Prevent an existing native Zen split-view group from being dragged into ordinary tab groups, including site-based groups and Zen folders.
- Guard Zia's direct DOM insertion and native browser movement APIs during a split drag. Invalid drops become no-ops before tab membership changes; no delayed move-back or ordering repair.
- Allow the split wrapper to move freely at the top level. Normal standalone-tab and whole-folder dragging remain native.
- Preserve any split views already nested by previous versions on initial launch; no forced session migration.

## Compatibility / known limitations
- Zia can still show its own folder drop preview, but the actual split insertion is rejected.
- Existing problematic nested split wrappers will not be automatically removed or disbanded.
- Real macOS 27.2 / Sine physical acceptance has not been performed.

## Verification
- Dedicated Node tests for split wrapper admission, split-pane API calls, original normal-tab behavior, restoration and re-arming.
- Native Zen 1.24b + pinned Zia integration test for attempted browser and DOM insertion into a Site Folder.
- Other existing tests must continue to pass before publication.

## Rollback
- If Sine does not support downgrading, temporarily disable this MOD; do not delete or forcibly ungroup user's existing tabs.
