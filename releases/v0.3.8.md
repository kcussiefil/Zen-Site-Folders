# Zen Site Folders v0.3.8

**Pre-release｜依使用者指示發布；實體觸控板與動畫觀感仍待驗收。**

## 修復

- 補齊一般網站群組缺少的原生收合／展開動畫入口，保留 Zia 對原生動畫的修飾，避免另加高度動畫或互斥收合 CSS。
- 修正原生切換分頁的焦點移交誤清除拖曳來源，解決部分分頁無法排序。
- 以拖曳前的實際排列計算落點，等待原生／Zia 落地結束再做一次校正；移除固定 38ms 的時序假設。Escape、新手勢及切換 Space 會取消過期校正。
- 解散群組、安全拆分與還原先等待接受的拖放完成，再擷取真正分頁物件的 DOM 順序；等待非同步移出及空群組移除後才驗證完成。
- 保留 SessionStore 原快照、封存讀回驗證、還原箭頭與未知群組保護；不透過關閉、重建或釘選分頁來修復。

## 驗證

- 六套 Node 回歸測試。
- 真正 Zen 1.24b + Zia 2.114.1 的分頁／群組 DOM、原生 API／事件／動畫、XUL 選單及 SessionStore 回歸測試，Linux 與 macOS 各十項。
- 同一套測試要求未修改的 v0.3.7 重現指定失敗，避免只驗證新程式。
- 輸入事件為合成事件，測試使用隔離無視窗設定檔。**不能據此宣稱使用者實機的觸控板或動畫手感已正常。**單獨同步解散在基準版已通過；這次修復包含拖放未完成及延遲移出的保序競態。

## 更新

透過 Sine 更新後，**完全結束並重新啟動 Zen**，避免舊版控制器仍留在同一視窗。不要清除快照或重建分頁。建議先在設定檔副本依 `docs/macOS-acceptance.md` 驗收。
