# Zen Site Folders v0.8.6 — Measured optical glyph balance

The previous v0.8.5 icon box adjustment did not create balanced artwork because the Zen SVGs have different painted paths and viewBoxes. Screenshot measurement at 538×74 (physical px) found actual visible outlines of Undo 22×26, Group 26×22, Clear 18×23.

## Fix
Normalize painted silhouettes with image-only transforms, keeping the native icon assets and original CSS sizing:
- **Undo**: 15×15 CSS px image, `scaleY(0.86)` to make the tall circular arrow less visually dominant.
- **Group**: 16×16 CSS px image, `scaleX(0.88)` to make the wide folder less visually dominant.
- **Clear**: 13×13 CSS px image, `scaleX(1.22)` to give the narrow arrow comparable visual width.

Based on the supplied screenshot, all three are expected to occupy about 22×22 screenshot pixels after calibration. Image transforms are centered, not animated, and do not alter any 20×20 button hitbox, right-aligned button position, hover-only fade, separator wave or DOM placement.

## Verification
- Node regression checks exact transforms, icon dimensions, unmodified hit targets and native Clear.
- Native Zen 1.24b + Zia WebDriver tests measure post-transform glyph rectangles, separator hover transitions and a real native Clear click on macOS/Linux.
- Screenshot visual acceptance on the user's macOS display is still required.
