# Zen Site Folders v0.3.4

**Pre-release — 尚待 macOS Zen + Zia 實機驗證**

### 收合後的選取分頁外觀
- 移除 v0.3.3 在群組收合後指定的自訂黑色背景、亮灰色玻璃外框及圓角。
- 讓展開與收合狀態中的同一個實際分頁都沿用 **Zia 原生選取分頁** 的 `--zia-active-tab-bg`、光暈與細緻邊緣，不再在完成開合時突然更換成另一套樣式。
- 繼續保留「收合資料夾後，目前正在看的分頁仍在標題下方」行為，不複製、不移動分頁。

### 動畫末端平順性
- 移除收合穩態強制指定的選取列最小高度，減少與原生分頁行高差異。
- WAAPI 備援收合時，以真實分頁高度加上 **tab 上下 margin 與容器上下 padding** 計算最終高度，減少完成動畫時跳動。
- Zia 原生 420ms 動畫優先；快速反向開合、動態四條音量波形及右側快速預覽維持不變。

### 範圍與驗證
- 一般分頁區、不釘選、新到舊排序、快照、Undo、安全拆分及右鍵選單邏輯不變。
- GitHub Actions 使用模擬回歸測試確認樣式不覆寫 Zia 選取背景、實際高度目標正確；但不等於 macOS Zen 的實際 UI／動畫驗證。
- 更新前先備份 Zen Profile，於測試工作區確認視覺過渡和目前分頁常駐。
