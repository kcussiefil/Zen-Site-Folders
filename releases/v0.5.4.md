# Zen Site Folders v0.5.4

**Zia-style live visual destination, with an exact drop contract**

- Modeled after Zia's native `measureRows → apply → finishFolderDrop`: the dragged group's existing floating preview takes the exact insertion slot opened by its sibling transforms. Moving up, moving down and remaining in place use the same row pitch and the same before/after decision.
- The existing card docks directly into the desired row; no second bar or duplicate native drag image. Group and single-tab drags retain earlier guardrails.
- On drop, a short visual bridge covers the synchronous native move so there is no initial disappearing row. Preserves stable post-drop safety reconciliation and keeps the source tab/group identity.
- Preserves auto-scroll, compact sidebar preview hold, Sine updatedAt, snapshot rescue, Zia animations and tab pinning limits.
- Native Zen+Zia CI validates slot coordinates and successful drop; macOS physical device smoothness still requires direct testing.
