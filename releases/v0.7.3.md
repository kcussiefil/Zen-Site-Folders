# Zen Site Folders v0.7.3 — collapsed single-member visibility and Zia glass parity

Fixes the v0.7.2 regression reported on macOS: closing a tab via the
Site Folders preview of a **collapsed, background** group auto-dissolved
the group but the surviving independent tab remained visually hidden.

- Once the native ungroup and independent placement complete, cancel only
  leftover height/min-height/opacity animations attached to the detached
  tab. Restore its native inline presentation, reveal it only when it
  belongs to the active Space and is unexpectedly hidden, and refresh Zen's
  cached visible-tab list. Run lightweight next-frame and close-animation
  checks without delaying the initial ungroup.
- Preserve the already working selected-tab in-place dissolution.
- Match Zia's real hover-glass presentation: same 76% backdrop tint and
  24px saturation blur when enabled, same zia-video bypass, and exactly
  the 0.5px pseudo-element border from Zia's zia.glass-off mode. Observe
  changes to the video's CSS gate live.
- Do not change hover-card width, row padding, time display, icons,
  drag/drop, grouping thresholds, snapshots or genuine timestamp logic.

Hardware macOS visual verification is required for the final judgement of
glass/edge fidelity. Related JS and native Zen/Zia tests gate the release.
