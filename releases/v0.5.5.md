# Zen Site Folders v0.5.5

**Whole website-group dragging now uses Zia's actual single native drag controller.**

On native dragstart, the grabbed ordinary site group is transiently recognized by Zia as a folder. Zia alone then owns the live displaced rows, visual position, and final drop. Site Folders does not draw its second card or run a competing visual controller. A narrowly scoped, same-drop-cycle safety check restores the original unpinned DOM position only if native Zia/Zen mistakenly sends a plain tab-group into the pinned container; already-correct drops are untouched. The adapter restores the original group identity and any transient Zen method wrapper after the gesture. Prevents nested site-folder drops, preserving top-level grouping and SessionStore snapshots. Without Zia or a native dragstart, the previously verified pointer-only fallback remains. Sine timestamps, vertical edge scroll and compact-mode hover previews remain unchanged.

CI includes direct Zia takeover, non-nesting and cleanup tests; physical macOS gesture testing remains necessary.

Fixed the no-dragstart handoff: crossing the pointer threshold starts the fallback immediately, including privileged synthetic events reported as trusted. A subsequent accepted Zia dragstart removes the fallback visuals and retains the original measured layout. Pointer release and cancellation restore the transient identity. Ownership no longer depends on `event.isTrusted`.
