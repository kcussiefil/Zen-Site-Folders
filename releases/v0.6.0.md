# Zen Site Folders v0.6.0

整合網站資料夾拖曳、跨群組分頁處理，以及選取分頁配色與預覽介面調整。

- 資料夾落定直接使用 Zia 預覽位置；保留已確認的單次排序處理，避免先放錯再搬回。
- 外部分頁丟入已收合網站群組時，依 Zia 的實際預覽目標，在第一次插入時排到最上方；已展開群組與同組排序維持自由落點。
- 加入群組時同步整理選取列，移出時解除舊組的隱藏樣式；來源收合群組不再多啟動一次收合動畫。
- 加入時清除舊收合清單的起點位移，避免它和 Zia 落定動畫重疊；針對往下拖的裁切，只暫時放寬原先可容納內容的容器及 shadow scrollbox，保留真正長清單的捲動。
- 針對按下後清單位置改變，校正 Zia 拖曳起點；保留原生後續追蹤及邊緣捲動。
- 選取分頁配色改放分頁右鍵選單，所有一般分頁共用顏色／不透明度；按鈕適配明暗主題，還原預設靠左，取消與儲存靠右。
- 預覽加寬、加入細緻邊緣及可靠開啟時間；關閉按鈕僅滑鼠移入該列時顯示。About 使用 Zen 資料夾圖示與較細箭頭，保留目前分隔線。

## 驗證狀態與限制

針對 Zen 1.24b（20261029123729）、Zia 2.114.1、Sine 2.3.4.1c，使用 macOS 隔離設定檔開發。程式回歸與腳本語法檢查的結果另行記錄；本次未執行完整 CI 或完整原生瀏覽器矩陣。

最後一輪實機曾觀察到「往下拖被裁切」與「放開後大幅彈遠再回來」，本版包含針對這兩項的最新調整，但尚未完成修正後的視覺驗收，不能宣稱已完全消除。一次新建分頁的 OS 滑鼠測試沒有命中預期加入預覽，且畫面擷取失敗，因此不算視覺 PASS。長距離捲動、所有落點、動畫觀感與明暗主題完整驗收仍待確認。

窄圖示側欄的既有零高度限制仍保留。Zia 內部處理器不符預期特徵時不介入，不保證其他 Zia 版本相容。
