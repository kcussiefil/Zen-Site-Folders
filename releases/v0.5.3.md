# Zen Site Folders v0.5.3

**修復拖曳回歸，保留 Sine 更新及側邊欄預覽修正**

- 停止 v0.5.1／v0.5.2 在拖曳進行中直接移動真實 DOM，以免和 Zia 原生拖動預覽衝突；恢復 v0.5.0 的已驗證安全落點架構。
- 恢復整個資料夾拖動時其他分頁／資料夾上下讓位動畫，並以標題列高度計算位移，過渡 110ms，減少大群組跑版。
- 保持沒有重複灰色水平落點線。
- 加入只有 `mouseup`、沒有 `drop` 時的拖曳完成備援；原生拖放不雙重提交。
- 保留 v0.5.2 已修復的緊湊模式預覽時側邊欄顯示、Sine 版本偵測，及自動邊緣捲動。
- 不調整分頁身份、釘選、快照、安全拆分與 Zia 本體。

macOS 觸控板、影片播放及側邊欄的完整流暢度需實機確認。
