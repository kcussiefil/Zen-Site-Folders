# Zen Site Folders v0.9.9 — native manual groups

## New
- Drag a **standalone ordinary tab** onto the center of a second standalone tab. After a 180 ms hover, a temporary noninteractive **new group** preview appears. Moving off the center cancels the preview. Releasing over the candidate creates a real Firefox/Zen **un-pinned** tab group.
- Select two or more standalone tabs with Command and choose **建立普通群組** (Create ordinary group) in the native tab context menu.
- A mixed-site group is named **新群組** with Zen's own folder SVG. A same-site group takes the website title and native favicon.
- Manual groups are marked separately from automated Site Folders. Their label and icon can be changed from the existing Site Folders group context menu, and their ownership metadata is persisted by native group ID for session restore.

## Safety and compatibility
- No DOM moves while hovering, no tab recreation or reload, no implicit pinning, and no changes to original tab/linkedBrowser objects.
- Only standalone tabs in one active workspace qualify. Excludes Essentials, pinned, split, Glance, cloned, grouped, closing or synthetic tabs, and multi-selected drag gestures.
- Drops on tab edges continue to use native Zen/Zia tab ordering. Native background tab drag remains independent.
- Escape, drag end, or window deactivation cleans up the hover candidate.
- To disable the new **drag** gesture without removing the module: set `zen.sitefolders.manual_group_drag.enabled` to `false` in `about:config`. Manual multi-select via right click remains available.

## Verification
- Native Zen 1.24b + Zia macOS and Ubuntu test scenarios for unpinned real group creation, hover-to-drop and no early DOM grouping.
- Node regressions covering hover cancellation, icon/title selection, persisted manual ID, context-menu creation and pref-disabled guard.
- Existing unrelated held-background-drag CI failure remains documented from v0.9.5 onward.
- Physical macOS drag appearance and cursor behavior are not verified by headless browser CI.

## Rollback
- Reinstall v0.9.8 or disable drag creation through `about:config`.
