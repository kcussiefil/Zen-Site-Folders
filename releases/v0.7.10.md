# Zen Site Folders v0.7.10 — Repair split-folder layout

## Changes
- Fix the v0.7.9 regression where expanding a Site Folder containing a nested Zen split made all rows overlap older groups.
- Restore Zen's native split-aware `animateCollapse` and `animateExpand` routines so the negative `groupStart.marginTop` shift and individual row heights are settled correctly.
- Keep split panes owned by their native `tab-group[split-view-group]`; the ordinary bridge no longer writes individual split-pane heights or strips their labels.
- Retain v0.7.9 selected-tab color support for split wrappers and the protected single-member auto-dissolve guard.
- Add a real Zen/Zia integration regression checking the native split wrapper, row rectangles, zero start margin, and preserved titles after expand/collapse.

## Compatibility / known limitations
- Native split layout is tested in pinned Zen 1.24b with Zia, where available. macOS 27.2 visual verification is still needed.
- Does not change non-split ordinary-group animations or drag sorting.

## Verification
- Node regression and native Zen/Zia isolated integration case: `nested split expanded folder has nonoverlapping native layout`.
- macOS manual: split two pages, move both into a Site Folder, expand/close multiple times, and verify unrelated rows and page names.

## Rollback
- Revert Sine to v0.7.8 for a known version without the v0.7.9 split branch (split support incomplete there).
