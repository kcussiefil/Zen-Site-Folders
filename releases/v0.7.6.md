# Zen Site Folders v0.7.6 — Zia 2.118 video hover-card compatibility

Fix the Site Folders group preview losing its glass/translucent appearance on
video pages when the pointer moves from the Zen compact sidebar onto a group
preview card. The fix is independent of HDR Guard.

- Follow Zia 2.118's root `zia-video` state for the hover-card compositor,
  including its new **Blur over video** preference. Do not separately block
  composition merely because the selected browser still contains a video.
- Match Zia's protected-video hover-card paint: 88% opaque background,
  still translucent, **without blur** when `zia-video` is active.
- With **Blur over video** enabled, match Zia's normal 76% opaque blur
  and permit the compositor only while the Site Folders card is visible.
  Zia warns that blurring a video can dull colours and HDR video loses HDR.
- Keep the preview's native-style sound animation, time column, spacing,
  selected-item fill, expand/collapse behaviour, drag/drop and undo unchanged.
- Align the Node regression suite and native Zen+Zia CI reference with Zia
  v2.118.0.

Verification: repository Node regression checks and the existing native
Zen+Zia Linux/macOS suite are used for release validation. Final display
behaviour on macOS 27.2 with the user's installed HDR/SDR and other mods
remains a separate device-level acceptance check.
