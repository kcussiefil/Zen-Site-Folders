# Zen Site Folders v0.8.0 — Version carry-over correction

## Changes

- Correct the release number from the historical v0.7.10 to v0.8.0, in accordance with the mandatory 0–9 carry-over policy (`v0.7.9 → v0.8.0`).
- The split-view folder layout fix introduced in v0.7.10 is included unchanged: use Zen's native split-aware expand/collapse animation to restore row geometry.
- Update the manifest, Sine release metadata, release policy, version assertions and automated publication gate. The only change to a runtime script is its non-executable `@version` comment.
- Do not rename, overwrite or delete the historical v0.7.10 tag/release.

## Compatibility / known limitations

- Functional implementation is identical to historical v0.7.10. No new animation, drag, grouping, selected-color, layout or state-restoration logic is introduced.
- Native Zen/Zia integration tests passed for split-view geometry on Linux and macOS CI in the preceding release. Physical macOS 27.2 Sine acceptance remains pending.
- The separate macOS native bottom-edge pointer test was already failing before this metadata-only correction.

## Verification

- Check the new version-policy test, previous Node regression suite, Sine manifest and publisher gate.
- Existing split-view tests and native browser checks continue to apply to unchanged runtime behavior.
- Verify that Sine reports v0.8.0 and that a split tab inside a Site Folder opens without overlaying unrelated rows.

## Rollback

- If the existing split-view implementation still has a runtime regression, return to v0.7.8 in Sine while investigating. Version-only changes cannot fix an unresolved browser compatibility issue.
