# Zen Site Folders v0.9.8 — restore Sine update detection

## Fix
- The v0.9.7 GitHub Release and main branch were correctly published, but `theme.json.updatedAt` was accidentally left at **2026-11-12T19:05:12.824Z**.
- Sine uses the manifest's `updatedAt` comparison rather than the semantic `version` for mod update detection. This prevented the update from being offered.
- Advance `theme.json.updatedAt` to **2026-11-15T21:08:37.959Z** and publish the correction as **v0.9.8**.
- Add a CI regression test which compares the current timestamp to the previous tagged release, preventing another silent failure to detect updates.

## Runtime changes
- **None.** JavaScript, CSS, tab order, dragging, Zia asleep icons and other features are identical to v0.9.7.

## How to update
- Open Zen → Sine Mods → check for updates or use its Update control. After installing, restart Zen if requested.
- If no update is shown immediately, manually refresh Sine's mod update check. Do not uninstall your existing MOD or delete its configuration.

## Verification and known limitation
- The `updatedAt` comparison is confirmed in Sine's own `src/core/manager.sys.mjs` source.
- Node regression tests validate the manifest and release timestamp; no runtime code was modified.
- Previously documented native held-background-drag CI issue remains unrelated.

## Rollback
- v0.9.7 remains available on GitHub Releases.
