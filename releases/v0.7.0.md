# Zen Site Folders v0.7.0

Zia 2.117.3 live-preview paint compatibility (experimental until native macOS visual acceptance).

- On every Site Folders preview opening, read Zia's **native folder/card computed styles** for colour, background opacity, backdrop blur, glass edge/shadow, border, corner and text colour. Existing Zia-derived CSS remains a fallback until the native card is created.
- Observe Zia settings and root theme changes, as well as new native card creation, to refresh the preview without polling or mutating Zia's DOM.
- Keep the necessary web-compositing layer while the separate Site Folders preview is visible. Do not force that layer on a selected page with a visible video, following Zia's new SDR/HDR colour protection.
- Remove Site Folders' separate decorative hairline; use Zia's actual edge/shadow styling instead.
- Retain existing preview dimensions, tab-age information, sorting, drag and drop, animations, and saved group data.

**Known limitation:** A visible video may intentionally make the background translucent without true blur. Other Zia-native components may independently activate compositing. Native macOS Zen rendering remains to be verified before publishing.
