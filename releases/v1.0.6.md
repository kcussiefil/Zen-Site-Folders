# v1.0.6 — Recover manual grouping after native sorting

## Fixes

- Correct the v1.0.5 permanent sorting latch. Dragging across a tab's far edge still gives normal sorting to Zen/Zia; once the pointer comes to rest in a tab's central band for **150ms** (within 4px movement), the *same drag* may enter the normal group preview again. No need to release and start a fresh drag.
- While the pointer continues moving across rows, native `dragover` events are not blocked during recovery. Refresh natural source/target row geometry after Zia's native sorting before showing the root-fixed upper/lower preview.

- Two lower-row favicons now have **8px of visible separation**, with no negative margin or overlap.
- The X visible next to the `2` count is a native close/reset control, not the previously removed `setDragImage` call. Hide the original tab close/reset X only while the manual `新群組` preview is present, using a root-scoped attribute; restore all controls on drop/cancel/reorder/Escape.
