# Zen Site Folders v0.9.7 — preview background links and native Zia icon brightness

## Fixes
- When selecting a member of a collapsed Site Folder from the hover preview, a related background link may incorrectly append at the bottom of the group (Firefox Bug 2003021). Within that preview-selected context only, correct the tail placement with native `gBrowser.moveTabAfter` after insertion settles.
- Keep the natural ordering of consecutive background links and respect `browser.tabs.insertRelatedAfterCurrent`. Do not alter tab selection, manual scrolling, pinned tabs, other groups, or the background-drag engine.
- The v0.9.6 favicon compensation multiplied the opacity of a parent-filtered header. Replace it by a direct per-icon Zia fade: 0.55 for dark and 0.75 for light when **all group tabs are pending**; any loaded member restores full brightness.
- Preserve Zia's header text and chevron fade (0.60 dark, 0.80 light) independently from the site favicon; keep hover geometry and motion unchanged.
- Reuse the tab's native favicon source whenever available, falling back to Firefox's cached `page-icon:` URL for unloaded tabs.

## Verification
- Added/updated static CSS and hover-card state regressions, including consecutive related tabs and pref-disabled handling.
- GitHub CI native held-drag check is already failing in published v0.9.5 and v0.9.6; a passing static suite does not replace real macOS validation.
- This is a test candidate, not a published stable version.

## Rollback
- Reinstall v0.9.6 from GitHub Releases or revert the v0.9.7 branch changes.
