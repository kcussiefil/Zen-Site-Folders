# Zen Site Folders v0.8.4 — Stationary right-hand separator icons

## Fix
- Zen's native Clear became invisible in v0.8.3 when a selected, sound-playing or PiP tab was protected. The previous code incorrectly treated the missing `can-close` attribute as if there were no other closable tabs. Keep the native Clear icon and its original `cmd_zenCloseUnpinnedTabs` command available. Override Zen's native icon-level `display:none` when `can-close` is absent, without overriding the user preference that can disable the entire native button.
- All actions are visually **right aligned** and permanently anchored: **Undo → Organize/Group → native Clear**.
- When the row is not hovered, icons fade to zero opacity without moving or shrinking. The **line**, not the icons, extends across the separator. When the row is hovered, the line shortens and all applicable icons fade in **at the exact same positions**.
- Undo still disappears entirely when no valid per-workspace pre-sort snapshot exists. In that state no empty Undo slot remains: line reserve is calculated for two controls, Group and Clear.
- The sorting wave follows the native separator's actual width instead of clipping against invisible fixed-position buttons.

## Scope
- Retains Zen's original Clear command, grouping/undo callbacks, right-click rescue, split drag guard, Sine data and saved sessions unchanged.
- Only separator CSS, wave measurement and release metadata changed.

## Tests
- Native Zen 1.24b + Zia WebDriver pointer test now includes icon right-to-left ordering, fixed positions through hover transitions, hidden Undo/no snapshot behavior, missing can-close state, and real Clear click removing eligible tabs.
- Node regression and existing unrelated native tests retained.

## Rollback
- If Sine does not support reinstalling v0.8.3, disable Site Folders temporarily; do not clear browsing data as a workaround.
