# v1.0.3 — Centre-band manual grouping and adjustable hold

## Changes
- Keep the original two tab slots stable when a dragged ordinary tab approaches its destination. Only after crossing the target's central 30–70% region does the normal Zen/Zia neighbour avoidance resume.
- Require 150ms of stable overlap, then a horizontal hold fill (default 1.2 seconds). Expose a decimal-number text input under the Sine mod gear via `preferences.json` (0.3–2.5 seconds; 0.1-second precision). Invalid values safely fall back; out-of-range values are clamped in the runtime.
- For adjacent A→B and B→A grouping, show `新群組` in the original upper row and overlapping dragged/target favicons in the lower row. Upward grouping moves the pair down into its final slot in 170ms.
- At release after the fill, create one ordinary unpinned Zen tab group, placing the **dragged tab first** and destination tab second. The group itself remains anchored to the original upper row.
- Avoid a live DOM reorder while a grouping candidate is active, retain ordinary edge sorting, and cancel premature centre drops without accidentally reordering.
- Keep original native tab objects, background-drag protections, snapshot handling and existing site group behaviour unchanged.

## Compatibility / known limitations
- Applies to dragging eligible standalone ordinary tabs. Non-adjacent merges fall back to a single existing target row rather than hiding unrelated intervening rows.
- Sine renders the numeric seconds as an editable text field because slider/number-specific controls are not supported uniformly. Enter values such as `1.2`.
- The native Zen/Zia drag event ordering, visual landing behaviour and touchpad input require actual macOS acceptance. Passing source checks is not a claim that motion regressions are eliminated.

## Verification
- GitHub Actions: JavaScript parsing, preferences metadata validation, manual grouping unit checks, CSS/style parity, and native Zen + Zia browser tests on Linux/macOS.
- Manual acceptance: drag A downward into B, B upward into A, cross B's centre to reorder, release before the hold, change the seconds in Sine, restart Zen and confirm persistence.

## Rollback
- Restore the prior v1.0.2 release via Sine, or disable manual drag grouping with `zen.sitefolders.manual_group_drag.enabled=false` in `about:config`. Other Site Folders actions remain available.
