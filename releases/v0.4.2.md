# Zen Site Folders v0.4.2

**Pre-release｜影片播放時開合彈跳與收合分頁狀態修正；實機影片負載仍須驗收**

- 修正 v0.4.1 在已收合的網站群組切換作用中分頁時，可能同時呼叫 Zen 的展開與收合動畫，導致原生 Zia 微彈跳被覆蓋；現在每次狀態切換只啟動一條原生動畫路徑。
- 清理由前一個作用中分頁留下的 `folder-active`、高度及透明度狀態，確保收合群組內只顯示新選取的分頁；重新選取時仍恢復原生高度。
- 將開合事件同步合併至微任務，讓 Zia 的原生動畫監聽器先接收事件，避免多重重複處理。
- 移除收合且含作用中分頁時對整個群組套用的 `clip-path`，也避免展開狀態不必要的 `:has()` 裁切比對，以降低音量波形及影片播放期間的重繪負擔。
- 將 `TabSelect` 與分頁選取狀態變動的同步範圍縮至相關網站群組，減少垂直側邊欄額外掃描。
- **驗證**：Node 語法／功能回歸、Linux Zen + Zia 原生測試、macOS Zen + Zia 原生測試已通過；包含快速收合／展開、選取分頁切換、音訊標記、捲動位置、拖曳排序、解散與還原。
- 測試使用真實 Zen DOM 及模擬的 `soundplaying` 標記，**不等同於實際 YouTube 影片解碼與 GPU 負載測試**；影片播放時的流暢度仍須使用者在 macOS 實機確認。
- 不修改 Zia 套件、不關閉或重建分頁、不改變 SessionStore 快照格式與還原流程；與 Black Sheep POS 專案獨立。

更新後請完全結束並重新啟動 Zen，不需清除快照或重建分頁。
