# Zen Site Folders v1.0.2 — Yab-like horizontal folder creation and stable landing

## Drag-to-group interaction
- Replace the v1.0.1 favicon **circular progress** with Yab's **in-row choice**. The target tab row itself switches to a clean favicon + **新群組** + tab count; no separate floating translucent preview is created.
- After a 180ms reveal, the row fills **left to right** over 500ms. After the fill, the website icon changes to a folder. Release the pointer to create the group; move off target to cancel, leaving native tab order unchanged.
- When supported by Gecko's native drag dataTransfer, prefer the dragged website favicon as the drag image; keep the default Zen drag image if it cannot be set.
- The animation follows the distinct reveal and folder-hold phases in Yab's published `Sources/Fast/ColumnDrag.swift` and `Sources/Fast/TabDropChoice.swift`, reimplemented for Zen/Zia.

## Landing-order correction
- Fix the group insertion anchor: Zen's Tabbrowser implementation calls `insertBefore.before(group)`, so the group now anchors on the **hovered target**, not the first tab from a transiently reordered `gBrowser.tabs` list.
- Preserve native group membership order **hovered target first, dragged source second** in both drag directions. Avoid an additional after-the-fact group move.
- Never change the global `tabDragAndDrop._dontAnimateTabMove` flag at all (v1.0.1 had left it enabled); clear stale Zia drag translations only for the two committing tabs.
- Keep the prior Zia fixed-target anti-avoidance behavior, original tab objects, manual-group ownership, collapse, Site Folders styling and background tab drag path.

## Verification
- Node regression: horizontal completion/cancellation, no floating overlay, native target-first placement, both drag directions, safe animation state cleanup, and zero tab recreation.
- Real Zen+Zia macOS/Linux: check target row rendering, actual animated progress, readiness, native member ordering, and cleanup.
- The preexisting native consecutive held-background-drag failure (present since earlier releases) is tracked independently.

## Updating
- Sine manifest version and `updatedAt` advance together. CI validates update discovery against the previous release.
- Rollback: reinstall v1.0.1 from GitHub Releases or disable drag-to-group via `zen.sitefolders.manual_group_drag.enabled=false`.
