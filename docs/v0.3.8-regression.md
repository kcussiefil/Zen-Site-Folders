# v0.3.8 顯示回歸與 v0.3.9 修正

使用者錄影約第 11 秒按下還原後，分頁列表消失，僅目前分頁仍可見。已在隔離 Zen 1.24b + 相同 Zia 2.114.1 重現：A/C/D 分頁物件仍在且順序正確，但移出群組後保留 `height:0; opacity:0`。原測試的還原來源是展開的群組，漏掉收合且含目前分頁的情況。

此外，多個群組同時收合時，Zen 的共用動畫計數器會略過較早完成群組的最終隱藏。v0.3.8 對一般群組的橋接沒有補齊這一點，實測留下 `hidden=false`、5px 高度且 `overflow:visible` 的群組容器。Zia 對隱藏分頁的 pointer-events 與目前分頁光暈裁切規則，亦有部分只選取 zen-folder，未涵蓋本工具的一般 tab-group。

v0.3.9 在移動分頁前完成原生展開，讓原生動畫登記表清理實際分頁上的高度、透明度；不事後清除整份 style。每個群組只在自身最新原生動畫完成時補齊最終 hidden 狀態，不增加延時計時器。樣式只補齊本工具群組的原生裁切、點擊隔離與淡出規則，不自製高度動畫。還原的成功條件新增真正可見性；不可見時保留快照。

新增四個原生回歸案例：收合且含目前分頁後還原、手動解散、安全拆分，以及多群組同時收合與 elementFromPoint 命中自己標題的驗證。完整最終 CI 在 Linux/macOS 各執行原有案例與新增案例，並要求未修改 v0.3.8 重現上述四項失敗。輸入為合成事件，實體觸控板與使用者動畫觀感仍未驗收。

依使用者明確指示節省額度，集中修改後只做最後一輪必要驗證；通過即發布，不重複執行相同測試。未操作使用者目前的分頁、未清除快照、未修改已安裝設定檔。
